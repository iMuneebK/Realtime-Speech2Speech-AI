## Description
This project focuses on speech pipeline. It aims to provide a robust, efficient, and scalable solution using modern technologies and best practices in the field.

## Key Features
- High performance architecture
- Extensible and modular design
- Comprehensive data processing capabilities
- Easy-to-use interface and quick setup

## Tech Stack
- Whisper\n- Llama-3\n- XTTS-v2\n- PyTorch

## Quick Start
```bash
git clone https://github.com/iMuneebK/Realtime-Speech2Speech-AI.git
cd Realtime-Speech2Speech-AI
pip install -r requirements.txt
python main.py
```
